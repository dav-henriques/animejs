Linha do tempo

Três animações encadeadas numa única timeline, com sobreposição entre elas. Arraste o controle para avançar e voltar quadro a quadro.

Ver código 
const tl = anime.timeline({ autoplay: false, easing: 'easeOutExpo' });
tl.add({ targets: '.s-circle', translateX: dist, duration: 900 })
  .add({ targets: '.s-square', translateX: dist, rotate: 180,
         borderRadius: ['6px', '28px'], duration: 900 }, '-=600')
  .add({ targets: '.s-tri', translateX: dist,
         scale: [1, 1.4, 1], duration: 900 }, '-=600');

range.oninput = () => tl.seek(tl.duration * range.value / 100);

Curvas de aceleração

Mesma distância, mesma duração, curvas diferentes. É a curva que dá personalidade ao movimento. A mola ignora a duração e calcula a própria.

Parque do stagger

O anime.stagger distribui atrasos entre vários elementos. Escolha de onde a onda parte, inverta o sentido ou acelere a distribuição com uma curva.

Origem
Ver código 
anime({
  targets: '.bar',
  keyframes: [{ scaleY: 1, duration: 300 }, { scaleY: 0.12, duration: 700 }],
  delay: anime.stagger(40, { from: 'center', direction: 'reverse',
                              easing: 'easeInQuad' })
});

Morph de formas

Um único polígono de 72 pontos se transforma em outras formas animando o atributo points. Como todas têm o mesmo número de pontos, o anime.js interpola cada coordenada.

Parede de cartas

Toque em uma carta: o giro em 3D se espalha pela parede a partir dela. O verso de cada carta é um pedaço de uma imagem maior que só aparece inteira no fim.

Fogos em canvas

O anime.js não anima só o DOM: aqui ele anima objetos JavaScript comuns (posição, raio, opacidade) e um canvas desenha o resultado a cada quadro.

Números que contam

Animar um objeto como { valor: 0 } e escrever o resultado no update vira um contador. Os números abaixo são de exemplo, sorteados a cada clique.

Ver código 
const dados = { visitantes: 0 };
anime({
  targets: dados, visitantes: 48213, round: 1,
  duration: 1800, easing: 'easeOutExpo',
  update: () => el.textContent = dados.visitantes.toLocaleString('pt-BR')
});
